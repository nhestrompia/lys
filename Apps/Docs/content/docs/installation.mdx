## Download the app

Download the latest Apple-silicon release from [GitHub Releases](https://github.com/nhestrompia/lys/releases/latest).
Each release includes a Developer ID-signed and notarized `Lys-X.Y.Z-arm64.dmg` plus a SHA-256
checksum.

Open the DMG and drag `Lys.app` to **Applications**. Launch Lys from Applications, then approve
the macOS security prompt if it appears on the first launch.

## Requirements

- Apple Silicon Mac
- macOS 26.2 or newer
- Swift 6.2 or newer
- Full Xcode with an iOS Simulator runtime
- [AXe 1.8.0](https://github.com/cameroncooke/axe) for the in-app Simulator surface

After Lys discovers a supported Xcode and Simulator, it automatically downloads and builds the
verified WebDriverAgent runner in the background. This one-time setup is required for semantic
UI interaction and is shared by every supported coding agent; no separate setup action is needed.
The first launch may take a few minutes, and Lys shows its progress in **Settings → Compatibility
gates**.

## First project

Open an existing Git repository that contains an Xcode project or workspace, then select its app
scheme and an installed Simulator. Git repositories support isolated task worktrees; non-Git
folders are browse/build-only.

Lys uses Xcode as the compiler, SDK, Simulator, test, and signing infrastructure. It does not
replace the Apple toolchain. The GitHub release is the supported installation path; source builds
are only needed when contributing to Lys itself.
